# Current MVP — sanitised snapshot

This folder preserves the current MVP interaction model without any real employee information.

- The planning, routes, vehicle, times and metrics are synthetic demo data.
- The source application used a static PWA calendar, monthly navigation, focused daily details and offline caching.
- Real source PDFs, schedules, agent identifiers, route assignments and pay data are intentionally excluded.

This snapshot is a safe reference baseline for the LSD rebuild described in `docs/mvp.md`.
